The [source-observation specification](../../protocol/caesar-source-observations-2026-10-02.md) already documents the retrospective aggregation and raw-height limitations. It does not settle the genomic membership interpretation. Likewise, passing the baseline JSON validator establishes interface compatibility, not scientific release eligibility.

These are finite release tasks, not new universal requirements for biological admission. Exact feature-to-spectrum joins remain necessary only for methods and tracks that use spectra. Expansion can continue while the draft inputs are reviewed; no new source acquisition is needed to rebuild this matrix.
