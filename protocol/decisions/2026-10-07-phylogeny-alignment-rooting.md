# Marker alignment and rooting procedure

Frozen 7 October 2026 before any real alignment, tree or comparator score was inspected. Requested implementation route: gpt-6-astra / medium. No serving receipt was exposed. Humanizer applied.

Require the marker batch's final `complete` status and a verified completion record for every frozen versioned assembly. Recheck source, compressed input, native-output and eligible-marker hashes. Reconstruct marker eligibility from native single-copy exports and, for genome runs, the exact Miniprot PAF stop/frameshift join. A failed or unfinished extraction blocks this procedure; it cannot disappear from the denominator. Merge repeated exact versioned assembly identifiers, preserving their observation lists and rejecting conflicting inputs. Keep recovery and input mode visible, without reading chemical labels.

The population decision fixes marker occupancy at 80% of all unique assemblies and taxon recovery at 50% of all 1,122 fungi_odb12 groups. Count marker occupancy among passing taxa but retain every frozen assembly in its denominator. This conservative intersection does not regain occupancy by dropping low-recovery taxa. Report every excluded taxon and its observations. A reduced tree must state its actual coverage; it is never a full 66-assembly tree. Stop if fewer than four taxa or no markers survive.

Align each surviving amino-acid marker separately with MAFFT 7.526 L-INS-i (`--amino --localpair --maxiterate 1000 --thread 4`). The [MAFFT manual](https://mafft.cbrc.jp/alignment/software/manual/manual.html) describes local pairwise refinement for fewer than 200 sequences. This is suitable for this population size and handles partial conserved proteins. Missing taxa are added as gaps after alignment. Keep columns with canonical amino-acid residues in at least 50% of retained taxa, counting gaps and X as missing. Retain all raw alignments and one-based retained-column lists. This simple, fixed filter is a pragmatic rule, not evidence that each surviving column is correctly homologous. A marker with no surviving column is recorded as removed. Stop if any retained taxon has no canonical residue in the final matrix.

Concatenate in sorted marker order, preserving a partition-coordinate file. Infer one unpartitioned maximum-likelihood tree with IQ-TREE 2.4.0, fixed `LG+F+G4`, seed 20261007, four CPUs by default and a 2 GB IQ-TREE memory limit. LG is a general protein exchangeability model, +F uses observed amino-acid frequencies, and +G4 permits four categories of site rates; see the [IQ-TREE model documentation](https://iqtree.github.io/doc/Substitution-Models). The partition file records provenance and does not imply separately fitted marker models. A fixed model avoids fitting many candidate models across a roughly thousand-marker matrix on this eight-GiB host. This choice is made for reproducibility and bounded initial computation, not claimed model optimality. No support resampling is performed or implied by this initial tree. The [command reference](https://iqtree.github.io/doc/Command-Reference) documents the seed, checkpoint, thread and model options. Keep IQ-TREE checkpoints, reports, logs and unrooted Newick output.

This concatenated marker tree supplies comparative-method input. It does not resolve deep fungal evolutionary history: lineage sampling, compositional bias, heterotachy, gene-tree discordance and long branches can distort both topology and branch lengths. It is not a dated tree. Branch lengths are estimated substitutions per site.

Root with Biopython 1.85 at the midpoint of the longest tip-to-tip distance. The [Biopython tree API](https://biopython.org/docs/1.85/api/Bio.Phylo.BaseTree.html) defines this operation. There is no validated outgroup in this frozen population. Midpoint rooting is an estimate that depends on approximately balanced evolutionary rates and can move under long-branch sampling. Preserve the unrooted tree and label the rooted result accordingly. Do not treat this root as biological truth or tune it using downstream performance.

The BayesTraits handoff requires finite, nonnegative non-root edges, a positive total branch length and an exact, unique match to retained assembly IDs. This amends the initial conservative strictly-positive rule before any real inference: the separate adapter worker's native BayesTraits 3.0 synthetic zero-edge test returned finite likelihoods. Check before and after rooting and after serialization at 17-digit precision. Preserve zero edges, reject negative or nonfinite lengths and reject an all-zero tree. Do not add an arbitrary branch floor, drop identical taxa, or resolve polytomies with fabricated lengths. A failed check leaves the unrooted result and audit available, but produces no ready BayesTraits tree. Verify all pairwise distances survive rooting within numeric tolerance. Export rooted Newick and explicitly rooted NEXUS, plus population mapping and hashes. These outputs retain assembly identifiers and substitutions-per-site lengths; the adapter joins observation IDs through the mapping, rewrites translated NEXUS, and applies its recorded single mean-branch-length 0.1 scaling. Shared assemblies never create extra independent tree tips.

Resource amendment before real inference: production execution uses four threads by default after the complete-batch gate passes. The `--threads` option accepts one through four, retaining headroom on the eight-CPU host. Marker jobs remain sequential, and MAFFT and IQ-TREE receive the same selected count. The count is included in the analysis identity, so changing it requires a new output directory. Synthetic smoke remains fixed at one CPU while the four-CPU acquisition batch runs. Earlier one-CPU synthetic receipts remain unchanged. No alignment algorithm, trimming rule or substitution model changes. Real inference remains unstarted until the complete-batch gate passes. A separately labelled synthetic smoke run exercises the executables without importing real fungal markers or producing benchmark ranks. Repeated production commands reverify inputs and resume only a matching analysis manifest; mismatched settings or altered retained outputs fail closed.
